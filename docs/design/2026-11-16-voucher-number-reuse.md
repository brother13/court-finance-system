# 删除凭证后复用凭证号

## 1. 财务业务规则

- 同一账套、年度、期间内，自动编号优先分配有效凭证尚未使用的最小正整数。已删除凭证不再占用号码；未删除的作废凭证仍占用原号。
- 不修改其他有效凭证号；历史删除记录及其原号仍可通过备注、审计追溯。数据库唯一键如被历史软删正号占用，先将该历史记录避让到未占用负号。
- 号码预览只读；正式分配与凭证保存处于同一事务，失败整体回滚。
- 同批制证先按期间一次分配所需全部号码，再写入凭证，避免多个计划重复取得同一空号。业务分录、日期排序、金额和辅助核算规则不变。

## 2. 数据库

复用 `fin_voucher`、`fin_voucher_no_sequence` 及现有日志表，不新增字段或表。

序列行继续作为 `account_set_id + fiscal_year + period` 的并发锁；`current_no` 同步有效凭证及本批待保存凭证的最大号，不再直接用于推算下一个号。持锁后使用当前读获取有效号集合，避免旧事务快照漏掉刚提交的凭证。

## 3. 流程

预览：查询有效正号 → 返回最小空号，不写入。

保存：外层事务 → 锁序列 → 当前读本期间凭证 → 一次分配所需空号 → 历史软删号避让 → 更新序列 → 保存凭证、分录、辅助值和审计 → 提交。失败回滚。

删除及整理先锁同一期间序列，再更新凭证；删除后同步有效最大号。整理无凭证改号时也同步序列。

## 4. 接口

保留 `/voucher/nextNo`、保存、导入、删除和业务制证接口、参数与权限。内部增加统一号码服务及业务制证按期间批量取号回调。

## 5. 字典及档案

复用既有凭证状态和软删除标记；辅助档案不变。

## 6. 实现与验证

统一手工录入、业务制证和预览的空号规则；覆盖尾号/中间号删除、作废占号、批量分配、旧序列偏高、期间隔离、历史正号避让和回滚。同步 PHP 8 项目并保留其兼容层、认证及既有修复。
