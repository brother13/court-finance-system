# 辅助核算余额快照设计

## 业务规则

辅助核算余额表用于按科目、案号、收据号查询案款余额和未清收据。凭证、凭证明细、凭证辅助核算值、辅助期初余额仍是账务事实来源；快照表只是报表缓存，不能替代总账、明细账或辅助核算主数据。

## 数据库设计

新增 `fin_aux_balance_snapshot`，按 `account_set_id + fiscal_year + period + subject_code + case_no + receipt_no` 保存辅助余额汇总结果。金额同时保存期初借贷、累计借贷、期初余额、期末余额，便于列表和导出直接读取。

## 流程

查询辅助核算余额表时，先检查当前账套、年度、期间是否已有快照，以及凭证或辅助期初源数据是否晚于快照生成时间。源数据未变化时直接读取快照；源数据变化或无快照时，按原财务口径重算并覆盖当前期间快照。

## 接口

沿用 `/book/auxBalance` 和 `/book/auxBalanceSubjects`。前端不需要改变调用方式，导出继续使用页面数据。

## 字典档案

不新增业务枚举。`monitor_flag` 继续表示收据级期末余额非零，供案款未清监控使用。
