# 直接升级 PHP 与 ThinkPHP，保留现有账务和 MySQL

为处理 CVE-2026-109618、CVE-2026-109619 并减少重复迁移，用户于 2026-10-22 确认直接升级到 PHP 8.5 的已修复稳定版本，同步升级 ThinkPHP，不安排 PHP 8.2 的中间业务迁移。MySQL 升级不纳入本次范围，现有账务规则、账套隔离、UUID、表结构和历史数据以保留为目标；具体框架版本及数据库驱动兼容性仍需证据验证。

## Consequences

- 截至 2026-10-22，PHP 官方公布的 8.5 分支修复版本为 8.5.12；本机 8.5.2 仅用于离线兼容预检，不作为安全修复后的部署版本。
- 用户确认：历史缺陷单独登记；影响金额、凭证或数据安全的关键问题阻止上线，不能机械地以旧系统错误结果作为验收标准。
- 用户确认：正式切换最多预留两小时维护窗口；实际切换与恢复耗时须通过演练确定，不将两小时当作已验证的耗时承诺。
- 用户确认：由用户负责业务验收，技术验证和新旧账务结果对比由实施方提供。
- 本记录确认升级方向和已回答的约束；并不表示具体切换方案已确认、生产环境已核实或已授权立即切换。未决问题见升级前评审记录。

参考：[PHP 官方安全公告](https://www.php.net/archive/2026.php#2026-10-21-5)。
